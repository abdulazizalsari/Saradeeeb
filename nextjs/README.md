# Saradeeeb — Next.js migration (work in progress)

This directory is an **early scaffold**, not a feature-complete replacement for the PHP CMS. Public pages are placeholders; auth, writers, admin, database and uploads are **not yet implemented**. Do not use for production.

Run: `npm install && npm run dev` (from `nextjs/`).

For Vercel, set **Root Directory** to `nextjs`. Deploy previews only until the parity and security gates in `../VERCEL-MIGRATION-PLAN.md` are met. Do not point the production domain at this scaffold.

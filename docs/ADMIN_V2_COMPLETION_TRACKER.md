# متتبع إكمال Admin V2

آخر تدقيق: 13 أكتوبر 2026

## قرارات الأولوية الحالية

- Admin V2 هو الهدف الرسمي النهائي، لكن لا يتم تعطيل أو إعادة توجيه `/admin` قبل تكافؤ موثق وموافقة المالك.
- هوية Admin V2 الحالية: الوضع النهاري أبيض/أسود مع Garnet `#800020`، والوضع الليلي أسود/أبيض مع Garnet.
- لا تتم استعادة اللون الأخضر أو التركوازي السابق.
- `app/Controllers/AdminController.php` فارغ محلياً ولا يُعاد بناؤه بالتخمين.
- الموقع العام وبطاقات الكتاب الرسمية خارج نطاق تغيير لوحة الإدارة.
- لا يتم رفع حساب حقيقي إلى المالك تلقائياً، ولا تُجرى اختبارات مدمرة على قاعدة البيانات.

## ما تم التحقق منه

| أدوار المالك/المدير التنفيذي/المساعد | IMPLEMENTED BUT NOT FULLY TESTED | `admin_roles`, `AdminV2Rbac` |

| وحدات الصفحات والإعلانات والبودكاست | BLOCKED | مرتبطة جزئياً بـ`AdminController.php` الفارغ |

## تعليمات superseded

- لوحة Admin V2 الخضراء/التركوازية السابقة superseded by هوية Garnet الحالية.
- أي تعليمات سابقة لتعطيل `/admin` أو تحويله فوراً superseded by شرط التكافؤ وموافقة المالك.
- أي تصميم مستقل لدليل الكتاب لا يستبدل بيانات قاعدة البيانات الفعلية.

## الأولويات التالية

1. نقل وحدات مستقلة قابلة للتحقق إلى Admin V2: التعليقات، الوسائط، اللغات، المجتمع والرسائل.
2. بناء محررات حقيقية للمقالات والخواطر والترجمات مع حالات منفصلة للمراجعة والاعتماد والنشر.
3. إضافة سجل تاريخ المحتوى والإصدارات وربطه بالفاعل الحقيقي.
4. نقل الصفحات والتنقل والإعلانات والإعدادات فقط بعد تحديد منطقها من مصدر موثوق.
5. إضافة اختبارات آلية للصلاحيات والـCSRF والعمليات الآمنة.
6. إجراء اختبار متصفحي بصري للمقاسات المطلوبة قبل تقرير الجاهزية.
7. إعداد قائمة cutover وrollback ثم طلب موافقة المالك صراحةً.

## القيود الحالية

- لا توجد نسخة موثوقة متاحة من `AdminController.php` الفارغ.
- لم يتم توفير جلسة متصفح آلية؛ نتائج العرض المرئي غير مؤكدة.
- لا يمكن إعلان التكافؤ الوظيفي الكامل أو تنفيذ cutover الآن.

## الاسترجاع

لا توجد عملية rollback مدمرة مطلوبة للتغييرات الحالية: المigrations إضافية والجداول الجديدة مستقلة. لاسترجاع CSS أو كود Admin V2، استخدم نسخة المستودع/OneDrive الموثوقة قبل التعديل، ولا تحذف جداول الإنتاج أو تعيد ضبط قاعدة البيانات.

# سراديب – تحديث قاعدة البيانات وكلمة المرور

هذه الحزمة تخص **قاعدة البيانات فقط**؛ لا تحتوي على كود PHP أو ملفات واجهة المشروع.

المحتويات:
- `database/schema-full.sql`: مخطط قاعدة البيانات الكامل المتوفر من ملفات المحادثة (59 جدولًا)، دون أمر تعديل كلمة المرور.
- `migrations/password-reset-existing-user.sql`: أمر مستقل لإعادة تعيين كلمة مرور حساب واحد موجود.
- `SHA256SUMS.txt`: بصمات الملفات للمقارنة.

## لتغيير كلمة مرور مستخدم موجود
1. خذ نسخة احتياطية من قاعدة البيانات.
2. افتح `migrations/password-reset-existing-user.sql` وابحث عن `PUT_USERNAME_HERE`.
3. ضع اسم المستخدم الفعلي بدلًا منه (لا تستبدله ببريد إلكتروني).
4. نفّذ ملف التحديث **فقط** عبر MySQL/MariaDB أو phpMyAdmin.
5. تحقق من أن `updated_accounts` يساوي 1. القيمة 0 تعني عدم العثور على الحساب بالاسم المعيّن.
6. الكود يخزّن bcrypt hash ولا يخزن كلمة المرور النصية.

**تنبيهات مهمة:**
- المخطط الكامل مخصص لإنشاء جداول قاعدة بيانات جديدة؛ `CREATE TABLE IF NOT EXISTS` لا يُضيف أعمدة مفقودة إلى الجداول الموجودة، وليس ترحيلًا شاملًا لنسخة قائمة.
- لا تستورد `schema-full.sql` في قاعدة بيانات الموقع الحالية كبديل عن الترحيلات، ولا تستبدل قاعدة موجودة دون نسخة احتياطية وفحص التوافق.
- أمر إعادة تعيين كلمة المرور يفترض أن التطبيق يتحقق باستخدام `password_verify` في PHP أو آلية تدعم bcrypt.
- لا يغيّر الأمر كلمة مرور مستخدم قاعدة MySQL؛ إنه يغيّر كلمة مرور مستخدم داخل جدول `users`.
- هذه الحزمة لا تحتوي على بيانات فعلية للمستخدمين أو للمقالات أو إعدادات الاستضافة.
- لم يُجر اختبار تنفيذ SQL على خادم MySQL حقيقي ضمن هذه المحادثة؛ تم فحص البنية النصية والهاش فقط.

**للحصول على ZIP واحد يشمل المشروع كله مع هذه التعديلات داخل ملفات المشروع**، يجب تزويد الملف الأصلي الكامل الذي يحوي ملفات PHP والأصول؛ ZIP المرفوع سابقًا احتوى على ملفات SQL وتعليمات فقط.

# Saradeeeb — النسخة الكاملة المعدلة بتاريخ 16 أكتوبر 2026

## ماذا تتضمن؟

- ملفات المشروع البرمجية كاملة من أحدث أرشيف «النسخة الخاصة بوستنجر.rar» المرفق، مع مجلدات `app`, `assets`, `config` (بلا أسرار), `database`, `tools`, `tests` وباقي ملفات المشروع.
- الاحتفاظ بمخطط قاعدة البيانات الأحدث الأصلي `database/schema.sql` (حوالي 89 تعريف CREATE TABLE) وبترحيلات `app/migrations.php` دون استبدالها بمخطط أقدم.
- تعديل توافق غير إتلافي في `app/migrations.php` لإضافة عمودي استرداد كلمة المرور إن كانا مفقودين على قاعدة قديمة، قبل مسار العودة السريعة لبعض إصدارات الـ schema.
- سكربت تغيير كلمة مرور المدير بواسطة SSH في `tools/reset-admin-password.php`، يُطلب فيه إدخال كلمة المرور تفاعليًا ولا يُشغّل من المتصفح.
- ملف SQL اختياري **لمرة واحدة** في `database/hostinger/2026-10-16-reset-admin-password-ONCE.sql` لتعيين كلمة المرور التي تم اختيارها سابقاً، لحساب اسم المستخدم `admin` ذي الدور الإداري فقط.
- تحديث إرشادات Hostinger لكي لا يُظن أن ترحيلات قاعدة البيانات ستنفذ تلقائيًا على الموقع المنشور.

## ما لم يُدمج (عن قصد)

ملفات إعدادات قاعدة البيانات السرية من بيئة التطوير (`config/local.php`)، نسخ SQL الاحتياطية، مخزن `storage/dev-mysql` المحلي، السجلات وملفات الاختبار الناتجة، الأرشيفات المتداخلة والملفات المحلية الخاصة. يجب الحفاظ على ملفات الخادم هذه كما هي، وعدم رفع بيئة MySQL التطويرية إلى Hostinger. هذه حزمة مشروع كود كاملة وليست نسخة احتياطية من قاعدة الموقع المباشرة أو ملفاته الشخصية.

## ترقية موقع قائم على Hostinger

1. انسخ احتياطياً قاعدة البيانات والموقع كاملاً.
2. فك الأرشيف **داخل مجلد الاختبار أولاً**، ثم انقل ملفات المشروع إلى `public_html` بحيث يظهر `index.php` في الجذر وليس داخل مجلد جديد.
3. عند الاستبدال، **لا تمس** `config/local.php` الموجود، ولا محتويات `uploads/` و`storage/`.
4. لا تُعد تشغيل `install.php`. تحقق من الـ URL المناسب للموقع وتهيئة PHP.
5. الترحيلات على الإنتاج تتطلب الموافقة الصريحة عبر `APP_RUN_MIGRATIONS=true` أثناء نافذة الصيانة بعد النسخ الاحتياطي، ثم إرجاعه للوضع السابق وإزالة المتغير. إذا فشل أي تغيير راجع سجل الترحيلات واستعد نسخة الأمان عند الحاجة.
6. لتغيير كلمة مرور المدير: استعمل `php tools/reset-admin-password.php admin` عبر SSH، أو ملف SQL اليدوي الاختياري. لا تُنفّذ ملف SQL إذا لا تريد إعادة تعيين كلمة المرور. **لا يطبّق تغيير كلمة المرور بمجرد استبدال الكود.**
7. احذف ملف `install.php` بعد التثبيت، وامنع وصول الجمهور إلى أدوات الترقية/الإصلاح القديمة.

## فحوصات

- فحص PHP syntax لجميع ملفات `.php` بالحزمة.
- فحص وجود الملفات الأساسية ومخطط قاعدة البيانات والترحيلات.
- لم نختبر تكامل الموقع مع قاعدة Hostinger الحقيقية أو تسجيل دخول حقيقي؛ الاختبار التشغيلي مطلوب بعد النشر.
